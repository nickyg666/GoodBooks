### PART 1: USER GUIDE

**1. GETTING STARTED**

GoodBooks is a personal ebook library that automatically finds and downloads books from your Goodreads reading lists and sends them to your Kindle.

Key Features:
- Find books from Goodreads lists
- Download from Anna's Archive
- Auto-convert formats
- Send to Kindle
- Track your library

Access: http://localhost:5000 (or your public URL)

**2. THE LIBRARY VIEW**

Your main dashboard showing all downloaded books.

Each book displays:
- Cover image
- Title & author
- Date added
- File format

Actions you can do:
- Browse your library
- Send selected books to Kindle
- View book details (rating, genres, description)
- Send to Kindle via your device's browser

**Understanding Metadata Refresh:**

When GoodBooks runs, it processes your library to improve book information. For each book it checks:
- Has this book been processed before? (Checking...)
- Does it need updated information? (Fetching metadata...)
- Save the new information to disk (Saving...)

The progress bar at the top shows this real-time:
- **Book Title**: Which book is currently being processed
- **Step**: What stage (Checking, Fetching, Saving)
- **Progress Bar**: Visual indicator of completion
- **Percentage & ETA**: How far done and time remaining

Click the arrow to collapse the bar and reclaim screen space.

**3. SEARCHING FOR BOOKS**

Use the Search page to find and download new books without using feeds.

Steps:
1. Click Search
2. Enter book title or author name
3. Choose your preferred format:
   - EPUB (best for most devices - recommended)
   - MOBI (native Kindle format)
   - PDF (documents)
4. (Optional) Select preferred genres to filter results
5. Click Search
6. Browse results and download books you want

The genre filter helps you find books in specific categories while automatically excluding adult/explicit content for safety.

**4. MANAGING YOUR FEEDS**

Feeds are automatic book sources connected to your Goodreads lists.

**What the Feeds page shows:**
- List of your configured feeds
- **Remaining Books**: How many books from that list haven't been downloaded yet
- Last refresh date and time
- Manual refresh button

**To add a feed:**
1. Go to Settings
2. Add your Goodreads RSS URL or Goodreads list URL
3. Choose your format preference (EPUB, MOBI, PDF order)
4. Enable auto-send to Kindle (optional - sends books directly to your device)
5. Save

**To manually refresh:**
- Go to Feeds page
- Click "Refresh" next to a feed
- Watch the progress bar as it processes the list
- New books are automatically added to your Library

**5. HISTORY & DOWNLOADS**

View everything you've downloaded with detailed tracking.

Each entry shows:
- Book name
- Author
- Date downloaded
- Source (which feed or search)
- Status (completed, pending, failed)

**Actions you can perform:**

**Search History:**
- Use the search box to find books by title or author
- Quickly locate books you've previously downloaded

**Filter by Date Range:**
- View downloads from specific time periods
- Organize by week, month, or year
- See trends in your reading habits

**Additional options:**
- Click any entry to see full details
- View download source and format
- Re-download a book if needed

**6. SETTINGS (USER)**

Configure your account and preferences:

**Your Profile:**
- **Name**: Your username
- **Save Directory**: Folder where books are stored on the system
- **Kindle Email**: Your Kindle device email (get from Amazon account → Devices)
- **Kindle Type**: Device model (Paperwhite, Oasis, etc.)
  - Affects maximum file size allowed
  - Paperwhite: ~8MB, Oasis: ~10MB
- **Notification Email**: Where delivery confirmations are sent
  - Can be different from Kindle email
  - Receives summary of books sent

**7. ADVANCED FEATURES**

**Genre Filtering:**
Adult and explicit content is automatically filtered from public genre lists for a safer browsing experience. You can still find all books through direct search if needed.

**Cover Images:**
GoodBooks automatically finds and caches book covers for:
- Better library appearance
- Email notifications with cover thumbnails
- Device sync when sending to Kindle

Priority order:
1. Cached local copy (fastest)
2. Extracted from the ebook file
3. Downloaded from Goodreads
4. Placeholder if none available

**Format Conversion:**
If a book is in a format your device can't read, GoodBooks automatically converts it using Calibre. Examples:
- MOBI → EPUB (if you prefer EPUB)
- AZW → MOBI → EPUB (format chain)

Conversions may take 5-60 seconds depending on file size.

**Batch Sending to Kindle:**
When sending multiple books:
- Books are grouped intelligently (max 25 per batch)
- File sizes limited to 24MB per email
- Respects device limits
- You receive confirmation email
- Books appear on device within 5-10 minutes

**Multi-Format Support:**
- EPUB (recommended - universal)
- MOBI (Kindle native)
- AZW3 (newer Kindle format)
- PDF (documents and comics)

**8. TROUBLESHOOTING**

**Books won't download:**
- Verify internet connection is active
- Check that book title/author spelling is correct
- Verify Anna's Archive is accessible and has the book
- Try a different format or book

**Kindle not receiving books:**
- Verify Kindle email address in Settings (case-sensitive)
- Check email spam folder
- Ensure sender email is approved in Kindle account settings
- Check if file size exceeds device limit
- Wait 5-10 minutes (delivery can be slow)
- Try sending again with different format

**Missing cover images:**
- Book may not have embedded cover
- Goodreads source may not have cover available
- Re-add the book to refresh metadata
- Cover will be cached after successful fetch

**Feed stops working:**
- Goodreads link may have changed (re-copy from browser)
- List may no longer be public (check permissions)
- Try removing and re-adding the feed
- Contact system administrator if persists

### PART 2: ADMIN GUIDE

**9. SYSTEM ADMINISTRATION**

**Requirements:**
- Python 3.8+
- Calibre (ebook-convert command-line tool)
- 50GB+ disk space for library
- Internet connection (for Anna's Archive)

**Start application:**
```
python3 app.py
```

**Configuration (data/settings.json):**

Global system settings:
```
server_port: 5000          # Web UI port
log_level: INFO            # DEBUG for verbose logging
enable_background_jobs: true   # Auto-run feeds
max_feed_workers: 4        # Parallel feed processing
max_concurrent_downloads: 2    # Download threads
request_timeout: 30        # Seconds before timeout
```

**SMTP Setup (for email notifications):**

```
host: smtp.gmail.com       # Or your provider
port: 587                  # TLS port
username: your-email@gmail.com
password: app-specific-password  # Gmail: generate in account settings
from_email: sender@example.com
```

**User Configuration:**

Each user needs in settings.json:
- save_dir: Personal book folder path
- kindle_email: Device email from Amazon account
- notification_email: Confirmation email recipient
- feeds: Array of configured Goodreads sources

**Feed Configuration:**

- url: Goodreads RSS feed URL or HTML list URL
- mode: "rss" or "html"
- auto_send_to_kindle: true/false (explicit per-feed control)
- filetypes: ["epub", "mobi", "pdf"] (preference order)
- save_dir: (HTML mode only) custom save location

**Database Files:**

- data/settings.json: User & feed configuration
- data/library.json: Book metadata and details
- data/history.json: Download history entries
- data/covers/: Cached cover images (can grow large)

**Key Modules:**

- **app.py** (5,400+ lines): Flask server, feed processing, Kindle sending
- **parser_engine.py**: RSS/HTML parsing, Goodreads scraping
- **search_engine.py** (2,200+ lines): Anna's Archive search integration
- **settings_manager.py**: Configuration management, user/feed CRUD
- **ebook_metadata_extractor.py**: Metadata extraction, cover extraction, format conversion
- **cover_cache_manager.py**: Cover image caching system

**Logging:**

- logs/info.log: Normal operation logs
- logs/debug.log: Detailed debug output (enable with log_level: DEBUG)

Monitor system:
```
tail -f logs/info.log | grep ERROR
grep "Download" logs/info.log | tail -20
```

**Maintenance:**

**Weekly:**
- Review error logs for patterns
- Check disk space usage
- Monitor cover cache size

**Monthly:**
- Test SMTP settings (send test email)
- Verify Goodreads sources still work
- Check for stale files in data/temp/

**As Needed:**
- Clear data/temp/ (old temporary files)
- Archive completed history entries
- Update Goodreads scraping if page structure changes

**Performance Tuning:**

**For Faster Downloads:**
- Increase max_concurrent_downloads (be careful with rate limiting)
- Increase max_feed_workers
- Decrease request_timeout

**For More Stability:**
- Decrease max_concurrent_downloads
- Decrease max_feed_workers
- Increase request_timeout

**Disk Space Management:**
- Monitor data/covers/ (can grow to 50GB+)
- Archive old books regularly
- Use external storage if needed

**API Endpoints:**

**Library & UI:**
- GET / - Main library view
- GET /search - Search interface
- POST /search - Execute search
- GET /feeds - Feed management page
- GET /history - Download history
- GET /settings - Settings page
- POST /settings - Save user/feed settings

**Backend:**
- GET /metadata/progress - Server-Sent Events progress stream
- POST /queue/kindle - Queue book for Kindle sending
- GET /api/library - Raw library JSON data
